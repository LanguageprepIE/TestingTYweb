Pythagoras' Theorem

Master the theorem that changed geometry forever!

What is Pythagoras' Theorem?

Pythagoras' Theorem describes the relationship between the sides of a right-angled triangle (a triangle with one 90° angle).

In simple terms: If you know the lengths of two sides of a right-angled triangle, you can find the length of the third side!

This theorem is super useful in architecture, engineering, navigation, and even video game design. 🎮

The Formula

a² + b² = c²

What do a, b, and c mean?

  • a = one of the shorter sides (called a "leg")
  • b = the other shorter side (called a "leg")
  • c = the longest side opposite the right angle (called the "hypotenuse")

Worked Example 📝

Problem: A right-angled triangle has sides of 3cm and 4cm. What is the length of the hypotenuse?

Step 1: Write the formula

a² + b² = c²

Step 2: Substitute the values

3² + 4² = c²

Step 3: Calculate the squares

9 + 16 = c²

Step 4: Add them together

25 = c²

Step 5: Find the square root

c = √25 = 5cm

✓ The hypotenuse is 5cm

Common Mistakes to Avoid ❌

Mistake 1: Forgetting to square the sides

❌ Wrong: 3 + 4 = c (you need to square first!)

✓ Right: 3² + 4² = c²

Mistake 2: Using c on the wrong side

❌ Wrong: a² + c² = b² (c is always the hypotenuse, the longest side)

✓ Right: a² + b² = c² (c is opposite the right angle)

Mistake 3: Forgetting the square root

❌ Wrong: If a² + b² = 25, then c = 25

✓ Right: If a² + b² = 25, then c = √25 = 5
